# MoonPad

A polished Next.js prototype for an AI-powered token platform.

## Run it

1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Next.js.

## Current scope

This is intentionally a safe prototype: wallet connection, token launching, agent controls, charts, and activity are UI simulations. No real wallet keys are requested and no real transactions are executed.

Next integration phases can add a real Solana wallet connection, authenticated backend, token data, and explicitly authorized on-chain actions.
